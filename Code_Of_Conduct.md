# Code of Conduct

We aim to maintain a respectful, inclusive, and collaborative environment for everyone contributing to this project.

**Be respectful.** Treat others with courtesy and professionalism.
**Be constructive.** Offer helpful feedback and keep discussions focused on improving the project.
**No harassment or discrimination.** Personal attacks, derogatory language, or exclusionary behaviour are not acceptable.
**Stay on topic.** Keep interactions relevant to the project and its goals.

If you experience or observe behaviour that violates this Code of Conduct, please contact the maintainers at:
E.J.Hannon@exeter.ac.uk

Maintainers may take appropriate action, including warnings or removal from project spaces.
